
# AI Search

A multi-language framework for implementing and exploring artificial intelligence search algorithms.

## Implementations

- **C#** — .NET implementation.
- **TypeScript** — Node.js implementation.

## Algorithms

Planned and implemented algorithms may include:

- Breadth-First Search (BFS)
- Depth-First Search (DFS)
- Depth-Limited Search (DLS)
- Uniform-Cost Search (UCS)
- Iterative Deepening Search (IDS)
- Greedy Best-First Search
- A* Search

## Repository Structure

- `csharp/` — C# implementation.
- `typescript/` — TypeScript implementation.
- `docs/` — Shared documentation and design decisions.

## Goals

- Keep implementations organized by language.
- Use tests to verify algorithm behavior.
- Document algorithms and their assumptions.
- Compare implementations using consistent problem definitions and test scenarios.
